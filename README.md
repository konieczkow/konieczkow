# Maciej "Magic" Gajewski

I have been using computers since 1994, when I first managed to launch a DOS game without anyone's help. I built my first website more than 25 years ago; the oldest one I can still find in the archives dates back to 2001. I have worked as a professional software developer since 2010.

I specialize in Ruby and Ruby on Rails, but over the years I have also worked on projects involving JavaScript, TypeScript, Clojure, CoffeeScript, PhoneGap and Cordova, Objective-C, Go, Rust, Haskell, C, C++, C#, and Java.

Before AI shifted the center of gravity in software development, my technical interests often pulled me in two opposite directions: statically typed and low-level programming on one side, and domain-driven design on the other. I like understanding software across the entire abstraction stack—from memory and type systems to domain models and architecture.

These days, I spend much of my free time using AI to build applications I have always wanted but could never find enough time to create.

The latest example is [GridSnap](https://github.com/konieczkow/gridsnap), an open source alternative to Divvy for macOS.
